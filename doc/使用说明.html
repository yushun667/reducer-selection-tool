减速器选型计算工具 · 使用说明

版本 v1.0.0 ・ 对应仓库 yushun667/reducer-selection-tool ・ 本文档随工具更新

1 工具简介

本工具用于机器人关节减速器的概念设计与参数选型。输入需求（扭矩、转速、外径），工具实时输出全套几何参数、校核结论和 CAD 建模参数，并可一键导出图纸与零件模型。

工具自动在两种构型之间选择：

  • 单级行星减速器（NGW 型）：内齿圈固定，太阳轮输入，行星架输出。需求传动比在 3~9 且校核全过时使用。
  • RV 减速器（2K-V 一体化结构）：单级不满足时自动切换。无内齿圈、无输出柱销盘；行星轮轴即曲轴，双摆线轮 180° 错相与固定针齿壳啮合，行星架即输出端。速比 i = 1+(z_p/z_s)·(z_c+1)，适用范围约 16~300。

3 输入参数

3.1 需求参数

参数含义与说明
输入扭矩 T₁电机端扭矩（N·m）。与 T₂ 共同反推需求传动比 i* = T₂/(T₁·η)。
要求输出扭矩 T₂关节端需要的扭矩（N·m）。工具按 T₂ ≥ 需求 判定合格。
输入转速 n₁电机转速（rpm）。用于动载系数、输出转速和轴承寿命计算。
给定外径整机最大外径（mm），硬约束。单级模式为内齿圈外径，RV 模式为针齿壳外径。模数由它反解取标准系列。
输入轴直径太阳轮中心孔（mm）。输入轴支承由电机轴承承担，太阳轮常浮动安装。

3.2 经验选择

参数含义与说明
行星轮个数 n默认 3。n 多分担扭矩好，但邻接条件变紧、需浮动均载。
太阳轮齿数 z_s默认自动配齿（程序搜索达标组合）。切手动后可锁定；z<17 自动正变位防根切。
材料 / 热处理预设许用应力：20CrMnTi 渗碳（450/1200 MPa）、40Cr 调质（300/700）、45 钢调质（250/600）。
齿宽系数 φ_db = φ_d·m·z_s，常用 0.4~0.7。强度不足时程序自动加宽至 1.0。
齿形系数 Y_F弯曲强度估算用，≈2.5~2.9，查手册图。
均载措施 K_p浮动均载 1.15 / 无浮动 1.6。
工况系数 K_A平稳 1.0 / 中等冲击 1.25 / 大冲击 1.5。
针齿节圆比 D_p/DRV 模式。针齿节圆直径 = 比值 × 给定外径，默认 0.8。
短幅系数 K₁RV 模式。决定偏心距 e = K₁·R_p/z_c。压力角不足或曲线奇异时程序自动下调。
针齿最小直径RV 模式。针齿套外径下限（默认 3 mm）。实际取 max（弯曲强度需求, 该下限）对应的标准滚子。
滚套壁厚比 t/dRV 模式。针齿套与销的壁厚比例，下限 0.5 mm。

4 输出阅读

输出分四块：配齿与模数、全部几何尺寸、校核结论、CAD 建模参数表。校核结论红绿分明：绿 = 通过，红 = 未通过（悬停每行可见含义与对策）。任一红项时工具底部状态为红，RV 模式同理。

校核项含义
装配条件单级：(z_s+z_r)/n 须为整数，否则行星轮装不进。RV 无内齿圈，不适用。
邻接间隙相邻行星轮齿顶圆不相碰，间隙 ≥ 0.5 mm。
根切检查z<17 时程序自动取最小正变位并按变位后齿形绘制，本行恒绿。
弯曲 / 接触安全系数S_F ≥ 1.4、S_H ≥ 1.1（含 K_A、K_V、K_p）。
模数装外径单级：齿根圆+轮缘 ≤ 给定外径；RV：行星齿顶 ≤ 针齿内切圆（防干涉）。
强度是否足够实际模数 m ≥ 强度需求最小模数 m_est。
行星轮轴承 / 曲轴轴颈单级：行星轮孔 = 标准轴承外圈；RV：曲轴轴颈 = 滚针/球轴承内径，外圈即摆线轮曲轴孔。均校核壁厚强度与 L₁₀ 寿命 ≥ 5000 h。
太阳轮孔壁厚输入轴穿过太阳轮根圆后的剩余壁厚须满足强度。

RV 模式下增加 RV 面板：两级齿数与齿比 u、摆线轮参数（z_c、针齿数、偏心距 e、针齿、节圆、压力角、曲线有效性、外缘校核、厚度）、曲轴与轴承、摆线轮曲轴孔（孔数/分布圆/孔径）、整机速比与输出。

6 导出与建模

6.1 导出齿形 DXF（进 Fusion 360）

  1. 点"导出齿形 DXF"，得到分层文件（太阳轮 / 行星轮 / 内齿圈，或 RV 模式的太阳轮 / 行星轮 / 摆线轮 / 针齿孔位壳体），1:1 毫米。
  2. Fusion 360：设计 → 插入 → 插入 DXF → 选平面 → 单位选 mm → 勾选图层。
  3. 选中轮廓区域拉伸：齿轮按齿宽 b，摆线轮按 b_c（每盘厚度，共 2 盘，第二片转 180° 装配）。
  4. 装配行星轮中心距用工具输出的工作中心距 a（变位后可能大于标准值）。

6.2 一键生成零件 STEP（桌面应用）

  1. 点"一键生成零件 STEP"。
  2. 在弹出的系统窗口中选择零件保存位置，点"保存到这里"。
  3. 等待约 10~20 秒（窗口标题显示"正在生成零件…"），完成后弹出零件清单。
  4. 零件在所选文件夹的 rv-parts/ 下，每个零件一个独立 STEP：太阳轮、行星轮、曲轴（双偏心段一体）、摆线轮（共 2 盘）、针齿套（空心）、针齿销。单级模式为太阳轮、行星轮、内齿圈。

浏览器方式打开时，该按钮退化为下载 gen_rv_parts.py 脚本；双击 生成零件.command 自动调用 FreeCAD 完成生成，效果相同。

6.3 摆线轮精确建模

摆线轮也可用 Fusion 360 的 CycloidalDrive 脚本建模，参数照 CAD 表的"摆线轮"页逐项填（减速比 = z_c、偏心距、针齿直径、针齿节圆）。RV 结构学习与三维装配模型见 RV结构剖视示意图.html 与 resource/rv-structure/ 目录。

7 常见问题

现象原因与对策
太阳轮孔壁厚红输入轴太粗、太阳轮太小。减小输入轴直径，或加大外径/模数。
行星轮轴承/曲轴红行星轮根圆内放不下合格轴承。加大外径、降扭矩，或减小传动比分配。
针齿标红"受节距限制"针齿太密装不下粗针。减小"针齿最小直径"下限，或加大外径。
提示"RV 不适用"需求传动比 < 16。按提示调整（加大外径、提高材料等级、降扭矩）。
速比偏差 > 5%齿数取整所致。程序已在达标组合中选偏差最小者；可微调 T₂ 需求或接受转速误差。
针齿与行星轮在图上重叠不会重叠：RV 模式下行星齿顶被限制在针齿内切圆以内（灰虚线圈）。

8 模型假设与限制

本工具用于概念设计与方案比较。强度为简化估算，不含 GB/T 3480 的完整系数体系，无回差与刚度分析，效率取定值（η₁=0.97、η₂=0.9），轴承额定载荷为目录量级。变位按最小不根切自动取值。定型投产前必须按 GB/T 3480 完整校核，并进行结构与寿命复核。
