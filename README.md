# 减速器选型计算工具（Reducer Selection Calculator）

一个**单文件、零依赖、离线可用**的减速器选型计算工具。双击 `index.html` 即可在浏览器中使用，无需安装任何东西。

面向机器人关节等场景，覆盖两类方案：

- **单级行星减速器（NGW 型）**：内齿圈固定、太阳轮输入、行星架输出
- **RV 减速器（2K-V 一体化，纳博结构）**：无内齿圈、无输出柱销盘——行星轮轴即曲轴，双摆线轮 180° 错相与固定针齿壳啮合，行星架即输出端；速比为差动关系 i = 1+(z_p/z_s)·(z_c+1)。单级行星不满足需求时自动给出，配齿为 (z_s, z_p, z_c) 联合搜索（全部校核为约束，速比偏差最小为目标）

## 快速开始

- **原生桌面应用（macOS，Apple Silicon）**：从 [Releases](../../releases) 下载 `减速器选型工具.zip`，解压后把 `.app` 拖入"应用程序"。首次打开如提示"无法验证开发者"，在 系统设置 → 隐私与安全性 点"仍要打开"。
- **直接用浏览器**：双击 `index.html`（Windows / Linux / macOS 均可，无需安装）
- **或本地起服务**：`python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`
- **自行构建 .app**：`bash app/build-app.sh`（仅用 macOS 自带的 swiftc / sips / iconutil，无第三方依赖），产物在 `dist/减速器选型工具.app`
- 原理讲解页：打开 `planetary_gear_params.html`（工具内顶部有链接）

## 输入 → 输出

**输入（需求参数）**

| 参数 | 说明 |
|---|---|
| 输入扭矩 T₁ | 电机端扭矩（N·m） |
| 要求输出扭矩 T₂ | 由 i* = T₂/(T₁·η) 反推传动比 |
| 输入转速 n₁ | rpm，用于动载系数与输出转速 |
| 内齿圈外径 | 给定硬尺寸，模数由它反解 |
| 输入轴直径 | 太阳轮孔径（输入轴支承由电机轴承承担，太阳轮常浮动） |

**输入（经验选择）**：行星轮个数、太阳轮齿数（自动/手动）、材料热处理（σ_FP/σ_HP 预设）、齿宽系数、齿形系数、均载措施（K_p）、工况系数 K_A、摆线级经验系数（节圆比 / 短幅系数 K₁ / 针齿最小直径 / 套厚比）。

**输出**：全套齿数与模数、变位系数、各齿轮分度圆/齿顶圆/齿根圆、中心距、实际外径、输出转速与扭矩、十项校核结论，以及按 **Spur Gear / CycloidalDrive 插件配置项**逐行对照的 CAD 建模参数表（太阳轮 / 行星轮 / 内齿圈 / 摆线轮四张表）。

**一键出图出件**：

- **导出齿形 DXF**：全部齿形（含变位）+ 孔位 + 针齿孔位/壳体，1:1 毫米分层导出，Fusion 360「插入 → 插入 DXF」直接拉伸建模
- **一键生成零件 STEP**：下载参数固化的 FreeCAD 脚本，双击 `生成零件.command` 自动运行，输出独立零件 STEP（太阳轮 / 行星轮 / 内齿圈，RV 模式为太阳轮 / 行星轮 / 曲轴 / 摆线轮 / 针齿销套）
- RV 结构学习：`RV结构剖视示意图.html`（原理页 RV 章节有链接）

## 计算与校验能力

- 配齿三条件（同心 / 装配 / 邻接）实时判定，装配条件不满足时动画上肉眼可见
- 模数由给定外径反解并取标准系列，余量留给轮缘
- 强度估算：K_A（工况）× K_V（动载，由节线速度算），安全系数判据 S_F ≥ 1.4、S_H ≥ 1.1
- 校验驱动自动迭代：强度不足先自动加宽齿宽（φ_d ≤ 1.0），再按强度+轴承过滤重选齿数
- 标准件联动：
  - 单级行星轮轴承 623~6204 自动选型（壁厚按强度需求 + L₁₀ 额定寿命 ≥ 5000h）
  - RV 曲轴轴承滚针 HK 系列优先（外径小，摆线轮曲轴孔更紧凑），取满足强度的最小轴颈
  - 针齿 = 销+套，套外径由弯曲强度反推且不低于用户设定下限，取标准滚子
- 根切自动处理：z<17 自动最小正变位，角度变位工作中心距（渐开线方程），齿形按变位后绘制
- 摆线级：轮廓曲线、最小压力角、奇异点检查（与 [CycloidalDrive](https://github.com/woodenCaliper/CycloidalDrive) 插件同款算法）、短幅系数 K₁ 不达标自动下调、摆线轮外缘 vs 壳体校核
- RV 防干涉：行星齿顶限制在针齿内切圆以内（留 1mm 余量），图上画出界限圆
- RV 适用范围判定：需求传动比 < 16 时明确提示"RV 不适用"并给出调整建议，不硬凑方案
- 真实比例动画：行星轮系与摆线减速器（齿对齿啮合相位精确），图上直接标注输入参数、孔径与齿顶圆

## 模型假设与免责

本工具用于**概念设计与方案比较**，强度为简化估算（不含 GB/T 3480 的 K_A/K_V/K_Hβ 完整系数体系、无回差/刚度分析、效率取定值 η₁=0.97 / η₂=0.9、轴承 C 值为目录量级；变位仅按最小不根切自动取值）。**定型投产前必须按 GB/T 3480 完整校核，并进行结构与寿命复核。**
