行星齿轮（NGW 型）· 参数确定全流程演示

左侧是按你输入的参数真实配齿并实时绘制的行星轮系：太阳轮（中）→ 行星轮 ×n → 内齿圈（外圈固定）→ 行星架（输出）。下面的面板走完整个设计流程：传动比 → 配齿三条件 → 模数齿宽 → 强度校核。

下面每一步都按统一格式展开：输入这一步依赖什么 → 计算用什么公式 → 输出确定了哪些参数。

第 1 步配齿：传动比 → 三个齿数

输入目标传动比 i*（来自需求：电机转速 / 关节输出转速）、行星轮个数 n（选定，常用 3）、太阳轮齿数 zs（选定，≥17 不根切）。
计算内齿圈固定时 i = 1 + zr/zs，反解出：
zr = (i* − 1)·zs 取整　⇒　zp = (zr − zs)/2　⇒　实际 i = 1 + zr/zs
式中：zr、zp、zs — 内齿圈、行星轮、太阳轮齿数；i — 传动比（太阳轮转速 / 行星架转速）。zp 的公式来自同心条件（三者共轴，见第 2 步）。
输出zr、zp、实际传动比 i（齿数必须取整，所以实际 i 与目标 i* 略有偏差，面板里能看到）。i* 越大 zs 占比越小，受最小齿数限制，单级 i ≤ 9。

第 2 步校验：三个齿数 → 能不能装

输入第 1 步得到的 zs、zp、zr、n。
计算逐条验证（面板 ③ 实时显示的就是这三条）：
  • 同心条件（三个齿轮能否共轴）：zr = zs + 2zp标准齿轮必须严格满足；采用角度变位可放宽为"内外两对啮合中心距相等"。本工具按此式取整，自动满足。
  • 装配条件（n 个行星轮能否均布装入）：(zs + zr) / n = 整数
    式中：n — 行星轮个数。
    把 zs 调成 19：条件变红，画面上行星轮与齿圈的齿对不上——实物装不进去。
  • 邻接条件（相邻行星轮齿顶圆不相碰）：2a·sin(π/n) > da,p + (0.5~1mm)
    式中：a — 太阳轮与行星轮中心距，a = m(zs+zp)/2；da,p — 行星轮齿顶圆直径，da,p = m(zp+2)。左式是相邻两行星轮中心的弦距。
    把 n 调到 5 或把 i 调小（行星轮变大），齿顶圆就会碰上。
输出一组合格齿数 (zs, zp, zr)。任一条件不满足 ⇒ 微调 zs 回到第 1 步重算。

第 3 步定尺寸：扭矩 → 模数、齿宽 → 全部直径

输入输入扭矩 T₁（N·mm，来自电机额定/峰值扭矩）、合格齿数、齿宽系数 φd（选定 0.4~0.7）、材料许用弯曲应力 σFP。
计算齿根弯曲强度估算模数：
m ≥ ∛( 2·Kp·T₁·YF / (φd·n·zs²·σFP) )
式中：m — 模数（mm）；T₁ — 输入扭矩（N·mm）；n — 行星轮个数（扭矩由 n 个行星轮分担）；Kp — 载荷分配不均系数（见第 5 步）；YF — 齿形系数（≈2.5~2.9，查标准图）；φd — 齿宽系数；σFP — 许用弯曲应力（MPa）。
计算模数取标准值后，全部尺寸随之确定：
b = φd·m·zs　　d = m·z　　a = m(zs+zp)/2
式中：b — 齿宽（mm）；d — 分度圆直径（mm），代入 zs/zp/zr 得三个齿轮的直径；a — 中心距（mm）。齿圈分度圆 + 齿根 + 轮缘即整机外径 D，须满足空间限制。
输出m、b，以及太阳轮/行星轮/内齿圈的全部分度圆、齿顶圆、齿根圆直径，中心距 a、整机外径 D。D 超空间限制 ⇒ 减小 zs（配正变位）或改多级。

第 4 步变位：齿数已定 → 修形优化

输入已定齿数与 m；zs < 17 时为必做项。
计算太阳轮取正变位（变位系数 x > 0），齿圈相应负变位，保持中心距不变（高度变位）或按需要调整（角度变位）。
x — 变位系数，刀具相对标准位置的移距与模数之比；x > 0 正变位（齿根变壮、避免根切），x < 0 负变位。变位还可使外啮合（凸-凸接触，弱）与内啮合（凸-凹接触，强）等强度。
输出各齿轮变位系数 xs、xp、xr。

第 5 步校核：全部参数 → 合格 / 返工

输入第 1~4 步的全部参数 + 载荷 T₁、转速 n₁、材料热处理。
计算按 GB/T 3480 / ISO 6336 校核两对啮合（太阳轮-行星轮、行星轮-齿圈）：
σH ≤ σHP　（齿面接触疲劳）　　σF ≤ σFP　（齿根弯曲疲劳）
式中：σH、σF — 计算接触应力、计算弯曲应力（MPa）；σHP、σFP — 许用接触应力、许用弯曲应力（MPa），由材料、热处理与寿命系数决定。行星轮双侧啮合、受载次数多，是薄弱环节；且必须按"最累的那个行星轮"计入载荷分配不均系数 Kp：
均载措施Kp（n=3）
无浮动构件1.4 ~ 1.8
太阳轮或内齿圈浮动均载1.1 ~ 1.2
输出判定结论：合格 ⇒ 设计定型；不合格 ⇒ 加大 m 或 b，回第 3 步。

第 6 步补充：n 与均载的权衡

n 在第 1 步选定，但它同时影响两端：n 越多，每个行星轮分到的扭矩越小（第 3 步 m 可更小），但邻接条件越紧、且必须配浮动均载构件（太阳轮浮动 / 内齿圈浮动 / 行星架浮动）才能压低 Kp。n=3 对加工装配误差最宽容，是默认选择。
